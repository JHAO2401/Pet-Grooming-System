# Pet-Grooming-System

A Python-based pet grooming and care management system.

## Features

- Pet grooming appointments and management (`GroomingApp.py`)
- Pet feeding management (`FeedingApp.py`)
- Pet expense tracking (`PetExpenseTracker.py`)
- Veterinary visit management (`Vetapp.py`)
- Main menu navigation (`mainmenu.py`)

## Tech Stack

- Python 3
- Standard library only

## Project Structure

```
mainmenu.py          # Main menu / entry point
GroomingApp.py       # Pet grooming management
FeedingApp.py        # Pet feeding management
PetExpenseTracker.py # Pet expense tracking
Vetapp.py            # Veterinary visit management
data.txt             # Local data storage
```

## Getting Started

1. Clone the repository:

```bash
git clone https://github.com/JHAO2401/Pet-Grooming-System.git
cd Pet-Grooming-System
```

2. Run the main menu:

```bash
python mainmenu.py
```

3. Or run individual modules directly, e.g.:

```bash
python GroomingApp.py
```
